UX Aspects 14.0.0 is now available! Check out the documentation at [uxaspects.github.io/UXAspects](https://uxaspects.github.io/UXAspects).

#### Installation

```bash
npm install @ux-aspects/ux-aspects@14.0.0
```

#### New Features

- Angular 22 Support.

#### Breaking Changes (from UX Aspects 13.x)

- Angular 20 is no longer supported.

Any questions or feedback? Feel free to open an issue on [GitHub](https://github.com/UXAspects/UXAspects/issues)!
